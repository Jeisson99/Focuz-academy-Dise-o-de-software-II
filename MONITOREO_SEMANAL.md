## 1. Organización y medios de comunicación

Como primera etapa para la organización del proyecto, se establecieron los principales medios de comunicación y coordinación del equipo de trabajo. Para facilitar una comunicación rápida y constante entre los integrantes, se creó un **grupo de WhatsApp**, definido como el principal canal de comunicación para compartir información, avances, acuerdos, asignación de actividades y resolver inquietudes relacionadas con el desarrollo del proyecto.

De manera complementaria, se utilizó **Atlassian** como plataforma de apoyo para la gestión del proyecto y el trabajo colaborativo. Esta herramienta permitió organizar las actividades, realizar seguimiento a los avances y establecer una estructura de trabajo que facilitara la coordinación entre los diferentes integrantes del equipo.

De esta manera, el equipo logró establecer desde la etapa inicial una estructura organizada de comunicación, distribución de responsabilidades y planificación del tiempo, proporcionando una base adecuada para el desarrollo colaborativo del proyecto.
